# 运行时热键修改问题修复说明

## 问题分析

### 原因
之前的代码虽然保存了修改后的绑定到 PlayerPrefs,也同步到了 PlayerInput 实例,**但是忘记了重新布线输入监听**!

具体流程:
1. 游戏启动时 → `SkillQuickButtonBar.OnEnable()` → `WireInputActions()` → 启用并监听 InputAction
2. 修改热键 → `HotkeySettingsPanel.SaveBindings()` → 保存到 PlayerPrefs
3. **问题**: 虽然 PlayerPrefs 更新了,但 `WireInputActions()` 中监听的那些 InputAction 实例**没有重新布线**
4. 重启游戏 → `OnEnable()` → `WireInputActions()` → 使用新绑定 ✓ (所以重启后生效)

### 症状
- ✗ 运行时修改热键 → 不生效(因为监听的还是旧的InputAction实例)
- ✓ 重启游戏 → 生效(因为重新调用了WireInputActions)

## 修复方案

在 `SkillQuickButtonBar.RefreshHotkeyLabels()` 中确保两个关键动作:

1. **重新加载覆盖并同步 PlayerInput** — 让运行时 InputAction 拿到最新的键位 JSON。
2. **对运行时动作执行一次 Disable→Enable** — 避免缓存旧 Binding, 让新绑定立即生效。

如果发现输入监听尚未建立（`_wiredActions.Count == 0`），会在刷新末尾自动调用 `WireInputActions()`。

## 工作流程(修复后)

1. 玩家打开设置面板修改热键(例如将 Slot1 从 "1" 改为 "Q")
2. `RebindPromptUI.StartCaptureSingleKey()` 捕获按键 → 返回 `<Keyboard>/q`
3. `HotkeySettingsPanel.ApplySingleBinding()` → 应用到 InputAction
4. `HotkeySettingsPanel.SaveBindings()`:
   - 保存到 PlayerPrefs ✓
   - 同步到 PlayerInput ✓
   - 触发 `RefreshQuickBarLabels()` ✓
5. `SkillQuickButtonBar.RefreshHotkeyLabels()`:
   - 加载最新绑定 ✓
   - 将运行时动作 Disable→Enable 强制刷新 ✓
   - 如有需要自动补建输入监听 ✓
   - 刷新 UI 显示 ✓
6. 玩家按 Q 键 → 立即触发 Slot1 技能 ✓✓✓

## 测试步骤

1. 启动游戏
2. 打开设置面板,修改 Slot1 热键从 "1" 改为 "Q"
3. 关闭设置面板
4. **不要重启游戏**,直接按 Q 键
5. 应该立即触发 Slot1 技能 ✓

## 关键代码位置

## 注意事项

- 如果发现快捷栏在刷新后没有监听（例如特殊初始化顺序），系统会自动补线
- InputAction 在 Disable→Enable 后会立即采用新的 override
- 无需重启游戏即可使用最新热键
