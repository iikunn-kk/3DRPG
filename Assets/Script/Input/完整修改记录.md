```
2. 附加此脚本
3. 运行游戏
```

## 🐛 故障排除流程

```
问题：打包后不保存

1. 检查 Player.log
   ↓
   看到 "已保存资产" → ✅ 保存成功
   ↓
   没看到 → ❌ SaveBindings() 未调用
   
2. 检查 PlayerInput
   ↓
   看到 "找到 X 个 PlayerInput" (X>0) → ✅ 实例存在
   ↓
   看到 "找到 0 个" → ❌ 场景中无 PlayerInput
   
3. 检查同步
   ↓
   看到 "已应用覆盖到 PlayerInput" → ✅ 同步成功
   ↓
   没看到 → ❌ 同步失败，检查资产名
   
4. 检查刷新
   ↓
   看到 "刷新完成" → ✅ UI 更新
   ↓
   没看到 → ❌ 刷新未调用或失败
```
