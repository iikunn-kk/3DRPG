# 热键绑定打包前检查清单

## 📋 打包前必查项

### 1. 脚本配置检查
- [ ] `KeybindingStorage.cs` 中 `DebugLogs = true`（测试时）
- [ ] `InputBindingRuntimeSync.cs` 中 `DebugLogs = true`（测试时）
- [ ] `HotkeySettingsPanel.cs` 中 `debugRebindLogs = true`
- [ ] `SkillQuickButtonBar.cs` 中 `debugQuickbarLogs = true`

### 2. 场景设置检查
- [ ] 主场景中添加了 `InputBindingBootstrap` GameObject
- [ ] `InputBindingBootstrap.cs` 脚本已附加
- [ ] 所有 `InputActionReference` 字段都已正确赋值
- [ ] `HotkeySettingsPanel` 的 `onHotkeyChanged` 事件已连接（可选）

### 3. PlayerInput 检查
- [ ] 场景中存在 `PlayerInput` 组件
- [ ] `PlayerInput.actions` 字段已设置 InputActionAsset
- [ ] InputActionAsset 中的动作已正确配置
- [ ] 动作名称与引用中的名称一致

### 4. 构建设置检查
- [ ] 测试打包时启用 "Development Build"
- [ ] 测试打包时启用 "Script Debugging"（如果可用）
- [ ] 确认所有场景都已添加到 Build Settings
- [ ] 检查 Player Settings 中的公司名和产品名

## 🔍 测试流程

### 编辑器测试
1. [ ] 运行游戏，修改一个热键
2. [ ] 检查 Console 是否有保存日志
3. [ ] 重启游戏，验证热键是否保留
4. [ ] 检查快捷栏显示是否正确

### 开发构建测试
1. [ ] 打包为开发构建

## ⚠️ 常见错误标志

如果看到以下日志，说明有问题：

### ❌ 找不到 PlayerInput
```
[InputBindingRuntimeSync] 找到 0 个 PlayerInput 实例
```
**修复**: 确认场景中有 PlayerInput 组件

### ❌ JSON 为空
```
[KeybindingStorage] JSON为空，重置资产
```
**修复**: 检查 PlayerPrefs 保存权限

### ❌ 资产未设置
```
[KeybindingStorage] actionRef 为空
```
**修复**: 在 Inspector 中设置 InputActionReference

### ❌ 事件未连接
```
[热键] onHotkeyChanged 事件未设置！
```
**注意**: 这不是致命错误，兜底机制会处理
