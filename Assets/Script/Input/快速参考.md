## 🚀 最快 3 步修复

1. **场景中添加引导脚本**
   ```
   创建空 GameObject → 附加 InputBindingBootstrap.cs
   ```

2. **启用所有调试日志**
   ```csharp
   KeybindingStorage: DebugLogs = true
   InputBindingRuntimeSync: DebugLogs = true  
   HotkeySettingsPanel: debugRebindLogs = true
   SkillQuickButtonBar: debugQuickbarLogs = true
   ```

3. **开发构建测试**
   ```
   Build Settings → Development Build ✓ → 打包运行
   ```

## 📍 Player.log 位置

**Windows**: `%USERPROFILE%\AppData\LocalLow\<公司>\<产品>\Player.log`
**Mac**: `~/Library/Logs/<公司>/<产品>/Player.log`
**Linux**: `~/.config/unity3d/<公司>/<产品>/Player.log`

提示: Win+R → `%USERPROFILE%\AppData\LocalLow` → 找到你的游戏文件夹

## 📞 快速支持

**问题**: 所有步骤都做了还是不行？

**检查**:
1. Unity 版本 >= 2020.3？
2. Input System 包版本 >= 1.0.2？
3. Player.log 中是否有报错？
4. PlayerInput 的 Actions 字段是否为空？

**终极解决**:
```csharp
// 在 SkillQuickButtonBar.OnEnable() 加上
void OnEnable() {
    // 原有代码...
    
    // 强制延迟刷新（确保生效）
    StartCoroutine(DelayedRefresh());
}

IEnumerator DelayedRefresh() {
    yield return new WaitForSeconds(0.5f);
    RefreshHotkeyLabels();
}
```

**使用**: 创建 GameObject → 附加脚本 → 右键组件 → Context Menu

## ⭐ 核心原理一句话

**问题**: 编辑器用资产引用，打包后 PlayerInput 用运行时副本
**解决**: 保存到 PlayerPrefs，加载到所有实例，禁用再启用强制刷新
